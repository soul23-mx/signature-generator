          ¿Cómo instalar tu firma en cada cliente de correo?
          

            

              
                 Outlook para Windows (clásico / nuevo)
                
              
              

                
    
                  
  1. Pulsa Copiar HTML en este generador.
    2. 
                  
  2. Abre un Nuevo mensaje → pestaña Mensaje → Firma → Firmas…
    3. 
                  
  3. En la ventana Firmas y papel de carta, pulsa Nueva, ponle nombre y Aceptar.
    4. 
                  
  4. En Editar firma, haz clic derecho → Pegar como HTML (o Ctrl+Shift+V).
    5. 
                  
  5. En Elegir firma predeterminada, selecciona tu cuenta de correo (si tienes varias) y asigna la firma a Nuevos mensajes y Respuestas/reenvios.
    6. 
                  
  6. Pulsa Aceptar en ambas ventanas.
    7. 
                

              

            

            

              
                 Gmail (web)
                
              
              

                
    
                  
  1. Pulsa Copiar HTML en este generador.
    2. 
                  
  2. En Gmail, abre Configuración (⚙) → Ver todos los ajustes.
    3. 
                  
  3. Ve a la pestaña General y busca la sección Firma.
    4. 
                  
  4. Haz clic en Crear nueva, ponle un nombre y dale a Crear.
    5. 
                  
  5. En el editor, haz clic derecho → Pegar como HTML (o Ctrl+Shift+V).
    6. 
                  
  6. En Para nuevos mensajes y Al responder/reenviar, selecciona tu firma.
    7. 
                  
  7. Baja al final y pulsa Guardar cambios.
    8. 
                

              

            

            

              
                 Thunderbird
                
              
              

                
    
                  
  1. Cambia a la pestaña Código en este generador y copia todo el HTML (Ctrl+A, Ctrl+C).
    2. 
                  
  2. En Thunderbird: Menú (☰) → Configuración de cuenta.
    3. 
                  
  3. En el panel izquierdo, elige tu cuenta de correo → Configuración de firma.
    4. 
                  
  4. Marca Usar HTML.
    5. 
                  
  5. Pega el código en el cuadro (Ctrl+V).
    6. 
                  
  6. Pulsa Aceptar.
    7. 
                

              

            

            

              
                 Correo de Windows 10/11 (app Mail)
                
              
              

                
    
                  
  1. Pulsa Copiar HTML en este generador.
    2. 
                  
  2. Desde la bandeja de entrada: haz clic en el engranaje Configuración (⚙) (esquina inferior izquierda o superior derecha).
    3. 
                  
  3. Ve a Administrar cuentas → elige tu cuenta de correo (si tienes varias, repite el proceso para cada una).
    4. 
                  
  4. Selecciona Firma.
    5. 
                  
  5. Activa Usar una firma.
    6. 
                  
  6. Haz clic en el editor → Ctrl+Shift+V (pegar como HTML).
    7. 
                  
  7. Pulsa Guardar (o la flecha ← para volver).
    8. 
                

              

            

            

              
                 Apple Mail (iOS/iPadOS)
                
              
              

                
    
                  
  1. Pulsa Descargar .html en este generador.
    2. 
                  
  2. Ábrelo en el iPhone/iPad → mantén pulsado → Compartir → Copiar.
    3. 
                  
  3. Ve a Ajustes → Mail → Firma.
    4. 
                  
  4. Selecciona tu cuenta de correo (si tienes varias, configura cada una).
    5. 
                  
  5. Borra lo que haya y pega (mantén pulsado → Pegar).
    6. 
                

              

            

            
Consejo: Si al pegar se ve mal, usa siempre la pestaña Código y pega el HTML crudo en la configuración de firmas de tu cliente. Evita pegar desde la vista previa visual.
